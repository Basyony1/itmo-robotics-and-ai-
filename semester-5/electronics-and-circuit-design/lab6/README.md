# Lab 6: Logic gates in different logic families
# Лабораторная работа №6: Исследование логических элементов в различных логических семействах

**EN:** Basic logic gates (NOT, AND, OR, NAND, NOR) implemented in six logic families: diode-resistor (DRL), resistor-transistor (RTL), diode-transistor (DTL), transistor-transistor (TTL), single-type MOS and complementary MOS (CMOS). Truth tables and comparison of the families. Simulation in LTspice.

**RU:** Базовые логические элементы (НЕ, И, ИЛИ, НЕ-И, НЕ-ИЛИ) в шести логических семействах: диодно-резисторная (DRL), резисторно-транзисторная (RTL), диодно-транзисторная (DTL), транзисторно-транзисторная (TTL), логика на МОП-транзисторах одного типа (MOS) и комплементарная МОП-логика (CMOS). Таблицы истинности и сравнение семейств. Моделирование в LTspice.
