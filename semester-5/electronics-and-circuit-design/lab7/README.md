# Lab 7: Combinational and sequential logic
# Лабораторная работа №7: Комбинационные и последовательные логические элементы

**EN:** Combinational circuits: multiplexer, demultiplexer, encoder, decoder and binary adder, with truth tables for all input combinations. Sequential circuits: flip-flops, registers and counters, state tracking and transitions under clock and control signals. Simulation in LTspice.

**RU:** Комбинационные схемы: мультиплексор, демультиплексор, шифратор, дешифратор и двоичный сумматор, таблицы истинности для всех комбинаций входов. Последовательные схемы: триггеры, регистры и счётчики, анализ состояний и переходов при подаче тактовых и управляющих сигналов. Моделирование в LTspice.
