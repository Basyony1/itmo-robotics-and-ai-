# Lab 4: Typical dynamic elements
# Лабораторная работа №4: Типовые динамические звенья

**EN:** Transfer functions of physical objects in standard form (gains and time constants) and identification of the typical dynamic element for each one: a DC motor with and without armature inductance, a capacitor, a spring-mass system and an op-amp controller. Analytical and simulated time responses (step and impulse) and frequency responses (magnitude, phase, Bode plots).

**RU:** Передаточные функции физических объектов в стандартизированной форме (коэффициенты усиления и постоянные времени) и определение типового звена для каждого из них: двигатель постоянного тока без учета и с учетом индуктивности, конденсатор, пружинный маятник и регулятор на операционном усилителе. Аналитические и полученные моделированием временные (переходная и весовая) и частотные (АЧХ, ФЧХ, ЛАЧХ, ЛФЧХ) характеристики.
