# Lab 2: Free motion and stability
# Лабораторная работа №2: Свободное движение и устойчивость

**EN:** Free response of second-order systems for different root locations, analytical expressions for system modes, and the root stability criterion. Stability region in the (K, T₁) parameter plane of a third-order closed-loop system using the Hurwitz criterion. Synthesis of a command generator that reproduces a given reference signal.

**RU:** Свободное движение систем второго порядка при различном расположении корней, аналитические выражения для мод системы, корневой критерий устойчивости. Построение области устойчивости замкнутой системы третьего порядка на плоскости параметров (K, T₁) по критерию Гурвица. Синтез командного генератора, воспроизводящего заданный сигнал.
