## Lab 5: Accuracy properties of systems
**Лабораторная работа №5: Точностные свойства систем**

**EN:** Steady-state accuracy of closed-loop linear systems with unity negative feedback. Analytical and simulated computation of the steady-state tracking error for step, ramp and parabolic reference signals: final-value theorem, static gain and error coefficients, astaticism order κ and goodness factors K<sub>κ</sub>. Comparison of P-, I- and PI-regulators (gain K ∈ {1, 5, 10}, Table 3 parameter sets) and their effect on the error. Analysis of a disturbed system (control disturbance f₁ and measurement error f₂, structures a–d) and of a polynomial reference via a three-term Taylor expansion of the error transfer function W<sub>g→e</sub>(s). Step responses of output y(t) and error e(t), grouped by regulator gain.

**RU:** Точностные свойства замкнутых линейных систем с единичной отрицательной обратной связью. Аналитический расчёт и моделирование установившейся ошибки слежения при ступенчатом, линейно возрастающем и квадратично возрастающем задающих воздействиях: теорема о предельном значении, статический коэффициент передачи и коэффициенты ошибок, порядок астатизма κ и добротности K<sub>κ</sub>. Сравнение П-, И- и ПИ-регуляторов (коэффициент K ∈ {1, 5, 10}, наборы параметров по таблице 3) и их влияния на ошибку. Анализ возмущённой системы (возмущение по управлению f₁ и ошибка измерения f₂, структуры а–г) и полиномиального задающего воздействия через разложение передаточной функции по ошибке W<sub>g→e</sub>(s) в ряд Тейлора с тремя членами. Переходные процессы выхода y(t) и ошибки e(t), сгруппированные по коэффициенту регулятора.
