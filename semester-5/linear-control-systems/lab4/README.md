# Lab 4: Typical dynamic elements
# Лабораторная работа №4: Типовые динамические звенья

**EN:** Transfer functions of a DC motor (with and without inductance), a capacitor, a spring-mass system and an op-amp controller in standard form. Time responses (step, impulse) and frequency responses (magnitude, phase, Bode).

**RU:** Передаточные функции двигателя постоянного тока (без учета и с учетом индуктивности), конденсатора, пружинного маятника и регулятора на ОУ. Временные (переходная, весовая) и частотные (АЧХ, ФЧХ, ЛАЧХ, ЛФЧХ) характеристики.
