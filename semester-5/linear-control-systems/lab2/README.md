# Lab 2: Free motion and stability
# Лабораторная работа №2: Свободное движение и устойчивость

**EN:** Free response of second-order systems for different root locations, system modes and the root stability criterion. Stability region in the (K, T₁) plane using the Hurwitz criterion. Synthesis of a command generator.

**RU:** Свободное движение систем второго порядка при различном расположении корней, моды системы, корневой критерий устойчивости. Область устойчивости на плоскости параметров (K, T₁) по критерию Гурвица. Синтез командного генератора.
