# Linear Automatic Control Systems
# Линейные системы автоматического управления

Lab works with analytical derivations, MATLAB/Simulink models and LaTeX reports.

![MATLAB](https://img.shields.io/badge/MATLAB%2FSimulink-0076A8)
![LaTeX](https://img.shields.io/badge/LaTeX-008080?logo=latex&logoColor=white)

| # | Topic | What's covered |
|---|-------|----------------|
| 1 | [Models of linear dynamic systems](lab1/) | Input-output and state-space models, canonical forms, MIMO systems |
| 2 | [Free motion and stability](lab2/) | System modes, root and Hurwitz criteria, stability regions, command generator |
| 3 | [Forced motion and performance indices](lab3/) | Step response, degree of stability and oscillation, settling time, overshoot |
| 4 | [Typical dynamic elements](lab4/) | Frequency responses of a DC motor, capacitor, spring-mass system, op-amp |
| 5 | [Accuracy of control systems](lab5/) | Steady-state error, astatism, P / I / PI controllers, disturbances |
| 6 | [Input-output controllers](lab6/) | PID tuning with standard polynomials, tracking a sinusoidal reference |
